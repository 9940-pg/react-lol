## 🚀 डेप्लॉयमेंट मार्गदर्शक (Deployment Guide)

### पर्याय १: GitHub (Auto-sync with Vercel & Netlify)
प्रोजेक्ट गिटहबवर उपलब्ध आहे:
- **Repository:** `https://github.com/9940-pg/react-lol.git`
- **Branch:** `main`
- **Subfolder:** `nagarsevaksathi`

### पर्याय २: VERCEL वर Live करणे
1. **[vercel.com/new](https://vercel.com/new)** वर जा.
2. `react-lol` हा रिपॉझिटरी निवडा.
3. **Root Directory** च्या बाजूला `Edit` वर क्लिक करून **`nagarsevaksathi`** निवडा.
4. **Deploy** वर क्लिक करा. `vercel.json` आधीच कॉन्फिगर केलेला असल्याने थेट ३० सेकंदात लाइव्ह होईल.

### पर्याय ३: NETLIFY वर Live करणे
- **पद्धत अ (Netlify Drop - अवघ्या ५ सेकंदात):**
  1. ब्राउझरमध्ये **[app.netlify.com/drop](https://app.netlify.com/drop)** उघडा.
  2. `nagarsevaksathi/dist` फोल्डर तिथे ड्रॅग-अँड-ड्रॉप करा.
- **पद्धत ब (Git द्वारे):**
  1. **[app.netlify.com/start](https://app.netlify.com/start)** वर जा आणि GitHub सिलेक्ट करा.
  2. Base directory: `nagarsevaksathi`, Build command: `npm run build`, Publish directory: `dist`.
  3. **Deploy** वर क्लिक करा. `netlify.toml` आणि `_redirects` आधीच समाविष्ट आहेत.
